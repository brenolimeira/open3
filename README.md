### 🚀 Instalação

Clone o projeto

```sh
$ git clone https://github.com/brenolimeira/open3.git
```

Para Instalar todas as dependências do projeto use:

```sh
$ npm i
```

### Desenvolvimento

Para iniciar e contribuir com o projeto use as seguintes linhas de comando

Para iniciar aplicativo:
```sh
$ npm start
```
